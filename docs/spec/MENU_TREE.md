```text
=9.设置方法
=10.重新加载 Custom.cfg
================================
=0.返回
=00.刷新
================================
```

用户设置：

```cfg
alias scmd_custom1 "say hello"
alias scmd_custom2 "toggle cl_showfps 0 1"
```

持久化文件建议：

```text
Scmd/Custom.cfg
```

SCMD 启动时只做：

```cfg
execifexists Scmd/Custom
```
