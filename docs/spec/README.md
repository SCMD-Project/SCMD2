# SCMD 2.0 菜单设计规范 v1

SCMD = Shortcut Command

目标：
- 保留 SCMD 1.x 的经典控制台文本菜单风格。
- 适配当前 CS2：不依赖控制台自定义颜色。
- 所有页面统一 `0 = 返回`、`00 = 刷新`。
- 不自动抢占用户按键；绑定必须由用户明确发起。
- 提供“预设命令绑定”和 `scmd_custom1..8` 自定义命令槽。
- 快速跑图提供多种初始化方案，但初始化本身绝不自动绑定按键。
- “全部命令”是经过筛选和分类的实用目录，不塞纯开发内部垃圾。
- 武器菜单同时提供分类页和一张“全部武器”长页。
- 菜单与具体 CFG 实现分离；未来 SCB/字节码只优化执行速度，不改变 UI/ABI。

## 经典视觉规则

```text
================================
=|SCMD 2.0:\菜单\路径
================================
=分类:
=1.项目
=2.项目
================================
=0.返回
=00.刷新
================================
```

不用 Unicode 框线，不依赖颜色，避免中文宽度/字体/DPI 下错位。

## 公开命令 ABI

用户 bind 永远绑定公开 alias（例如 `scmd_noclip`），不绑定编译器内部名字。
详见 `PUBLIC_ABI.md`。

## 命令目录来源

设计时以当前 CS2 的 Source 2 `cvarlist` / GameTracking-CS2 命令与 convar dump 为基线，
删掉 crash、schema、渲染器内部、物理内部、测试框架等对普通玩家几乎无价值的项目。
最终发布前仍应由实机 `cvarlist` 快照再跑一次兼容检查。
